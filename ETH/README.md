# Web3 - 101 - Ethereum

## Contexto

Este es un tutorial dentro de [Web3 - 101](../README.md).

Ethereum es una plataforma descentralizada basada en blockchain que permite la creación y ejecución de contratos inteligentes (smart contracts) y aplicaciones descentralizadas (dApps). Su infraestructura es fundamental en el ecosistema Web3, permitiendo la transferencia de valor, la automatización de acuerdos y el desarrollo de soluciones innovadoras sin intermediarios.

### Características principales de Ethereum

- **Descentralización**: La red está compuesta por miles de nodos distribuidos globalmente, eliminando puntos únicos de fallo.
- **Ordenador mundial de liquidaciones**: Ethereum actúa como el principal ordenador mundial de liquidaciones, manteniendo un estado compartido y verificable para todas las transacciones y contratos.
- **Programabilidad**: Permite crear contratos inteligentes que automatizan procesos y acuerdos sin intermediarios.
- **Seguridad**: Utiliza criptografía avanzada y consenso para proteger las transacciones y los contratos.
- **Compatibilidad con Web3**: Es la base de la mayoría de las dApps y protocolos DeFi, NFT y DAOs.

### Aplicaciones prácticas

- **Desarrollo de dApps**: Creación de aplicaciones descentralizadas para finanzas, juegos, identidad, etc.
- **Contratos inteligentes**: Automatización de acuerdos, pagos, gobernanza y más.
- **DeFi**: Participación en protocolos financieros descentralizados (préstamos, exchanges, stablecoins).
- **NFTs**: Emisión y gestión de tokens no fungibles para arte, coleccionables y utilidades.
